# Telegram export parser

[[English version]](README.md)

Скрипт, который парсит `result.json` из экспорта чата Telegram.

Основная ценность проекта - структура Go-типов, в которую парсится экспорт чата. Формат экспорта нетривиальный, особенно в части текстовых сущностей и составных частей сообщения.

---

## Что умеет

- Читает JSON-файл экспорта Telegram.
- Распаковывает экспорт в Go-структуры.
- Фильтрует сообщения по дате.
- Записывает только текст сообщений в выходной файл.
- Может печатать сообщения в stdout в виде таблицы.
- Печатает размеры входного и выходного файлов.
